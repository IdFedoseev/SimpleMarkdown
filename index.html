Reader for macOS renders .md files the moment they open — no raw syntax, no preview toggle. Need a change? Edit the page itself, Notion-style, and it saves back to plain Markdown. Free and open source.

Edit the page, not the source

Select any text and a toolbar appears — bold, italics, code, links. Type / for a menu of blocks. What you touch is the finished document; what lands on disk is still clean Markdown. The round-trip is lossless.

Whole folders, one window

Drop a file or an entire folder anywhere on the window.

  • Sidebar browsing every file one click away; ⌘\ hides it when you want width.
  • Search ⌘F highlights every match with a counter and next/prev; Esc closes.
  • Autosave changes save themselves — an unsaved dot in the title bar tells the truth.
  • System default make Reader the editor for Markdown files; double-click just works.
  • Formats .md, .markdown, .mdown, .mkd, .txt.

Questions

How is Reader different from other Markdown viewers?

Most Mac viewers are read-only. Reader treats the rendered page as the editor: you fix and restructure in place, and the file stays plain Markdown.

Will it mangle my files?

No. The editor round-trips Markdown — formatting is stored as the same syntax you would type by hand.

What does it cost?

Nothing. MIT license, forever.

Which systems does it run on?

macOS. Reader is lightweight — it opens instantly and stays out of the way.
